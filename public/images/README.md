## 目录内容

| 文件 | 用途 | 在代码中的引用位置 |
|---|---|---|
| `bg/bg (1)~(7).png`、`bg/bg (1)~(4).jpg` | 全站背景图（每次访问随机选一张） | `src/config/images.js` → `bg` |
| `index.jpg` | 首页 Hero 大图 | `src/config/images.js` → `hero` |
| `card.png` | 工具卡片封面图 | `src/config/images.js` → `card` |

**如何替换**：把你自己的图片放进本目录，再修改
[`src/config/images.js`](../../src/config/images.js) 中对应的路径即可。
若把 `LOCAL_IMAGES` 里的某个键设为空字符串 `''`，前端会改为从网络图库拉取图片。

## 补充说明：网络图库来源

除本目录的本地图片外，前端还有一处**运行时降级逻辑**
（见 [`src/utils/animeImage.js`](../../src/utils/animeImage.js)）：
当本地图片未配置时，会依次从以下第三方图库请求图片 ——

- [nekos.best](https://nekos.best)
- [waifu.pics](https://waifu.pics)
- [pic.re](https://pic.re)

这些图片**与画师 Ashima 无关**，其版权与使用条件由对应图库决定。
本仓库不为其授予任何许可，也不对由此产生的使用后果负责。
