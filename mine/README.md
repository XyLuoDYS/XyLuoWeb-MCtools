# 我的贴图

这是「MC 贴图菜单生成」工具页的**自绘贴图**目录（位于项目根目录）。

把你画的按钮 / 图标贴图（PNG）直接丢进这个目录，工具页的「我的贴图」分组会自动列出，
不需要改任何配置。子目录也会被递归扫描。

- 文件名会成为界面上的显示名：`button_primary.png` → `Button Primary`
- 建议按贴图原始像素尺寸绘制（16×16、32×32…），工具里可以再等比缩放
- 透明背景会被保留；放置时按原始尺寸，超过画布时自动等比缩小

示例：

- button_primary.png
- button_hover.png
- icon_shop.png

> 原版容器贴图在项目根目录的 `vanilla/container/`，往里面加 PNG 也能被识别。
