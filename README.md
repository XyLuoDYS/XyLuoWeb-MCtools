## 部署注意（重要） | Deployment Notes (Important)

路由使用 **History 模式**（URL 不带 `#`，形如 `/mccolor`）。因此静态托管时**必须配置「所有路径回退到 index.html」**，否则刷新子页面会 404：
Routing uses **History mode** (URLs contain no `#`, e.g. `/mccolor`). Static hosting therefore **must be configured to rewrite all paths back to `index.html`**, otherwise refreshing a sub-page returns a 404:

| 平台 Platform | 做法 How |
| --- | --- |
| Nginx | `try_files $uri $uri/ /index.html;` |
| Netlify / Cloudflare Pages | 已内置 [`public/_redirects`](./public/_redirects)，开箱即用<br>Built in via [`public/_redirects`](./public/_redirects) — works out of the box |
| Vercel | 已内置 [`public/vercel.json`](./public/vercel.json)，开箱即用<br>Built in via [`public/vercel.json`](./public/vercel.json) — works out of the box |
| GitHub Pages / 纯静态托管<br>GitHub Pages / plain static hosting | **不支持**这种回退 → 请把 `src/router/index.js` 改回 `createWebHashHistory`<br>**No rewrite support** → switch `src/router/index.js` back to `createWebHashHistory` |

（若改用 `createWebHashHistory`，URL 会带 `#`，但无需任何服务端配置。）
(With `createWebHashHistory` the URL contains a `#`, but no server configuration is needed at all.)

**路由名不要和根目录文件名撞车**：`LICENSE`、`README.md`、`CONTRIBUTING.md` 这类根目录文件会被 dev server / 静态托管的「静态文件中间件」优先命中。例如路由写成 `/license`，浏览器返回的就是纯文本的 MIT 协议原文，而不是 SPA 页面。本站的条款页因此用的是 `/terms`。
**Never let a route name collide with a root-level file name.** Files such as `LICENSE`, `README.md` and `CONTRIBUTING.md` are matched first by the static file middleware of the dev server / static host. A route named `/license`, for example, makes the browser return the raw MIT text instead of the SPA page. This site's terms page therefore lives at `/terms`.

## 自定义 | Customisation

- **换背景图 / Hero 图**：把图片放进 `public/images/`，然后编辑 `src/config/images.js`。留空则回退到 `public/images/` 下的默认兜底图；本站**不请求任何第三方图库**。
  **Changing the background / hero image** — put the image into `public/images/`, then edit `src/config/images.js`. Leaving it empty falls back to the default file under `public/images/`; the site **never requests any third-party image API**.
- **加自己的贴图**：把 PNG 丢进 `mine/`，工具页「我的贴图」分组会自动出现，无需改配置。
  **Adding your own textures** — drop a PNG into `mine/` and it shows up in the "My Textures" group on the tool page automatically, with no configuration.
